## 📌 Overview

**Roblox Change Age** is a browser-based extension designed to provide a streamlined way to manage and update account age settings through a clean and modern interface.  
The project focuses on delivering a smooth user experience similar to native account settings panels.

---

## ✨ Features

- Age and birthdate selection system  
- Step-by-step validation flow  
- Status and progress feedback  
- Clean, Roblox-inspired interface  
- Lightweight and easy to use  

---

## ⚙️ Installation

1. Download the project files  
2. Extract the archive to a local folder  
3. Open Chrome and go to `chrome://extensions/`  
4. Enable **Developer Mode**  
5. Click **Load unpacked**  
6. Select the extracted project directory  

The extension will now be available in your browser.

The extension processes user input through a controlled flow that validates the selected data and applies the update sequence.  
Status messages and progress indicators provide real-time feedback during the operation.
